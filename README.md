# AreUOK - Steam Deck / Bazzite UU Monitor

A lightweight Decky Loader plugin to monitor the status of NetEase UU Accelerator on Steam Deck (Bazzite/SteamOS).

## Features
- Zero background CPU usage (pure on-demand Python backend).
- Auto-reset toggle UI to show real acceleration status.
- Clean, native SteamOS UI integration.

## Installation
1. Download the latest zip from the Releases page.
2. Copy the contents into `~/homebrew/plugins/AreUOK`.
3. Restart Decky Loader.

## Build from Source
Run `pnpm install` and then `pnpm run build`.
